# 工程表：個人事業主向け 1ページサービスサイト テンプレート

販売用フォルダは `products/service-site-template/` です。
このファイル（工程表）は制作用メモなので、販売ZIPには含めません。

## 方針

- HTML / CSS のみ。外部ライブラリ・外部フォント・JavaScriptは使わない
  （FAQの開閉は HTML標準の `<details>` で実現）
- フォーム送信など顧客データを扱う仕組みは入れない。
  問い合わせは「メールリンク」「外部の予約・フォームサービスへのリンク」で案内する
- 色・文字・余白は `css/style.css` 冒頭の `:root` でまとめて変更できる
- 編集箇所には `【編集】` コメントを付け、検索で見つけられるようにする
- 各工程で、スマホ幅（375px）とPC幅（1280px）の表示を確認してから次へ進む

## 工程

- [x] 工程1：ファイル構成と土台（HTMLの骨組み・CSS変数・共通レイアウト）
  - 確認：見出し6つが縦に並ぶ／背景が白とグレーで交互／375px幅で横スクロールなし／
    `--color-bg-sub` を変えるとグレー部分の色が変わる
- [x] 工程2：ヘッダー（屋号・ページ内メニュー・問い合わせボタン）
  - 確認：スクロールしてもヘッダーが上に残る／メニューで各見出しへ移動し、見出しがヘッダーに隠れない／
    320px幅でもメニューが切れない／768px以上で1段になる／Tabキーでメニューとボタンを順に選べる
- [x] 工程3：メインビジュアル（キャッチコピー・説明文・画像・ボタン）
  - 確認：スマホは「文章→画像」の縦並び・ボタンは横幅いっぱい／960px以上で左右2列／
    縦長・横長どちらの画像に差し替えても横4:縦3で表示／枠線ボタンにカーソルを乗せると塗りつぶしに変わる
- [x] 工程4：特徴（3つのカードを並べる）＋共通のセクション見出し
  - 確認：スマホ1列／約600pxで2列（3枚目は次の行）／768px以上で3列／
    カードを4枚に増やす・2枚に減らすとCSSを変えずに並びが変わる／文字のコントラスト比4.5以上
- [x] 工程5：料金（プラン表）
  - 確認：960px未満は1列（最大幅480px・中央）／960px以上で3列／ボタンの下端がそろう／
    「おすすめ」ラベルが上のカードに重ならない／is-recommended を別プランに移すと強調も移る／価格は税込表示
- [x] 工程6：ご利用の流れ（番号付きステップ）
  - 確認：番号が1から自動で付く／ステップを増やす・減らすと番号が振り直される／
    丸と縦線の中心がそろう／最後のステップの下に線が出ない
- [x] 工程7：よくある質問（`<details>` で開閉）
  - 確認：クリックで開閉／Tabで質問を選びEnter・スペースで開閉／開くと矢印が上向き／
    1問目は open 属性で最初から開く／長い質問でもQの丸がつぶれない
  - 未確認：Safari（Chromium以外のブラウザは工程9で確認方法を案内）
- [x] 工程8：お問い合わせ導線（メール・外部サービスへのボタン）とフッター
  - 確認：メールボタン・アドレスが mailto: リンク／外部ボタンは新しいタブで開き元のページは残る／
    「新しいタブで開きます」は画面に出ず読み上げのみ／受付時間の項目名と内容の位置がそろう／フッターから先頭へ戻る
- [x] 工程9：仕上げ（アクセシビリティ・表示確認・画像のダミー差し替え確認）
  - 実施：role="list"／「本文へ移動」リンク／キーボード操作時の枠線／動きを減らす設定への対応／
    特徴カードは768px未満で1列／DOCTYPEを大文字に
  - 確認：html-validate でエラー0（role="list" の重複警告は意図的なため除外）／7つの幅で横はみ出しなし／
    実際の縦長写真（3712×5568）に差し替えても4:3で表示
- [ ] 工程10：README・編集ガイド・Claude Code用指示文・利用規約
  - READMEに書くこと：公開するメールアドレスは迷惑メールが届く可能性がある（専用アドレス推奨）／
    ネットでサービスを販売する場合は特定商取引法の表示が必要になることがある（テンプレートには含まない）
- [ ] 工程11：販売用パッケージ（ZIP構成・商品説明文・スクリーンショット）
  - 商品説明の「動作確認環境」には、実際に確認したブラウザだけを書く
    （制作環境で確認済み：Chromium。Safari・Firefox・iPhone・Androidは実機で確認してから追記）
